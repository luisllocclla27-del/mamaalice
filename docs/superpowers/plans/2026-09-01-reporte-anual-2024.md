# Reporte Anual 2024 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create an interactive, scrollytelling web page (`reporte-2024.html`) that presents the 2024 Annual Report visually using animated counters and fade-in narrative blocks.

**Architecture:** A static HTML page with vanilla CSS (`styles.css`) and vanilla JS (`reporte.js`) using `IntersectionObserver` to trigger entrance animations. Reuses the existing `components.js` for header and footer injection.

**Tech Stack:** HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript (IntersectionObserver).

## Global Constraints

- No external libraries for animations (pure CSS + IntersectionObserver).
- Use placeholder text and images (`assets/images/`) as defined in the spec.
- Must be responsive (mobile-first approach).

- [ ] **Step 1: Write `reporte.js` for IntersectionObserver logic**

```javascript
document.addEventListener('DOMContentLoaded', () => {
    // 1. Counters Animation
    const counters = document.querySelectorAll('.counter');
    let hasCounted = false;

    const animateCounters = () => {
        counters.forEach(counter => {
            const updateCount = () => {
                const target = +counter.getAttribute('data-target');
                const count = +counter.innerText;
                const speed = 200; 
                const inc = target / speed;

                if (count < target) {
                    counter.innerText = Math.ceil(count + inc);
                    setTimeout(updateCount, 10);
                } else {
                    counter.innerText = target;
                }
            };
            updateCount();
        });
    };

    const counterObserver = new IntersectionObserver((entries) => {
        if (entries[0].isIntersecting && !hasCounted) {
            hasCounted = true;
            animateCounters();
        }
    }, { threshold: 0.5 });

    if(counters.length > 0) {
        counterObserver.observe(counters[0].parentElement.parentElement); // Observe the grid container
    }

    // 2. Fade Up Elements
    const fadeElements = document.querySelectorAll('.fade-up');
    const fadeObserver = new IntersectionObserver((entries, observer) => {
        entries.forEach(entry => {
            if (entry.isIntersecting) {
                entry.target.classList.add('is-visible');
                observer.unobserve(entry.target);
            }
        });
    }, { threshold: 0.2 });

    fadeElements.forEach(el => fadeObserver.observe(el));
});
```
